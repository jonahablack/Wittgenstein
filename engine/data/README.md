# data/

- `registry/` — the versioned, git-tracked bootstrap seed registry. See
  `registry/README.md` for its scope and status. This is the one subdirectory here
  meant to be hand-edited and reviewed like code.
- `examples/manifests/`, `examples/traces/`, `examples/corpus_profiles/` — synthetic,
  git-tracked example data generated by `scripts/generate_example_data.py`
  (`make examples`). These exercise the matching engine end-to-end and back the
  integration tests; they are not real production data.

A local SQLite dev database (`dev.db`, path set by `WITTGENSTEIN_DATABASE_URL`) is
created here at runtime and is gitignored — it holds the audit trail of submitted
manifests/traces/assessments/risk events (`src/wittgenstein/db/models/records.py`),
not the registry itself.
