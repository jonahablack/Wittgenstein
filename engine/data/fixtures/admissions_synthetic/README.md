# Synthetic medical school applications (fictional)

Three fictional applicant files for demonstrating Wittgenstein on admissions review. Every
person, school, hospital, publication and event here is invented. Applicants are identified
by number, as in blinded review. Each file has the parts an AMCAS-style application and a
secondary have: experiences (with hours), academics, a personal statement, a secondary
essay and letters of evaluation. `summaries.json` holds what an AI screening tool might
write about each file, including the kinds of errors such summaries make.
