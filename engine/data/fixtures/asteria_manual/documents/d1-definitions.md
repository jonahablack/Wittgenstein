# Asteria Autonomous Systems Certification Manual -- Definitions

Version 3.2, effective 1 March 2027. This is a fictional manual authored for
Wittgenstein's controlled synthetic-corpus regression tests. It is not a real
standard, regulation, or product manual, and none of its terms, thresholds, or
requirements apply to any real inspection unit.

## Definition D-01: Autonomous inspection unit

An autonomous inspection unit is a self-directed mechanical system designed to
perform structural inspection tasks without continuous human operation.

## Definition D-02: Class R inspection unit

A Class R inspection unit is an autonomous inspection unit intended for operation in
restricted-access industrial zones, as distinguished from a Class S inspection unit
under Definition D-03.

## Definition D-03: Class S inspection unit

A Class S inspection unit is an autonomous inspection unit intended for operation in
surface-level, publicly accessible zones.

## Definition D-04: Registered operator

A registered operator is a natural or legal person who has completed registration
under Article 5.

## Definition D-05: Conformity assessment

A conformity assessment is the documented process by which an inspection unit's
compliance with Article 2 is verified prior to deployment.

## Definition D-06: Reporting period

A reporting period is the twelve-month interval beginning 1 April of each calendar
year, distinct from a calendar year.
